# EDPay PrestaShop Module

[![PrestaShop](https://img.shields.io/badge/PrestaShop-1.7%20%7C%208.x-purple.svg)](https://prestashop.com)
[![Status](https://img.shields.io/badge/Status-Coming%20Soon-amber.svg)](https://edpay.co.mz)

Módulo oficial da **EDPay** para lojas virtuais **PrestaShop 1.7 e 8.x**.

---

## Funcionalidades

- Integração através do hook `paymentOptions` do PrestaShop.
- Suporte a Checkout Alojado (M-Pesa, e-Mola, Cartões Visa/Mastercard, Apple Pay, Google Pay).
- Atualização automática do estado da encomenda para `PS_OS_PAYMENT` após confirmação do webhook.
- Prazos e Condições: Tarifa plana de 6% em MZN, saques entre 2 a 7 dias úteis.
